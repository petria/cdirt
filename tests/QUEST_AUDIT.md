# C-Dirt quest completion audit

This is the source-derived route ledger for the 23 quests other than
Excalibur. It follows each active `set_quest()` hook in `specials/` back to
the zone records in `data/ZONES/`. Notes describe source expectations unless
listed in Runtime results. Start each quest from a fresh disposable
`cdirt:latest` container and use regular object, combat, and quest commands
after entering the area.

## Runtime evidence protocol

For each row, use a throwaway player in a newly started temporary container,
with normal quest actions and no object grants or state editing. Record the
commands and complete actor output; direct `goto` is only for reaching remote
test rooms and does not verify the walking/puzzle route to those rooms. For
broadcast or transport triggers,
also connect a same-room witness and a remote witness. Check `quests` after
the trigger, then repeat any action that can consume or mutate an item. If a
route cannot be completed, record the first blocked command, exact output,
and relevant source condition instead of marking it verified. Never connect
this audit runner to the live port 6715 instance.

The quest runner covers the 23 non-Excalibur quests in this ledger. Excalibur
has a separate runtime runner. Keep a quest marked uncovered until its dedicated
scenario passes in a fresh disposable server.
